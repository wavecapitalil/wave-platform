# תורת הנרות היפניים — סביבת עבודה

**סטטוס: פיתוח פעיל; אין עדיין שיעורים מאושרים לפרסום.**

מטרת התיקייה: מאגר עבודה גרסאי לפיתוח משותף של קורס תורת הנרות היפניים. **אין להשתמש בתכנים באתר החי ללא אישור מפורש.**

## כללי יסוד
- 56 שיעורים בעשר יחידות; הקורס מיועד למתחילים מאפס.
- התמקדות בנרות יפניים; תבניות בשם כוללות נר אחד או שניים בלבד.
- עברית עם מונחים מקצועיים באנגלית.
- תרשימי נרות מקוריים, איורי אנטומיה והבחנה בין דוגמאות סינתטיות לנתונים היסטוריים.
- ניתוח טכני, מתנדים וניהול סיכונים הם כלים תומכים.
- לא לייחס לתבניות אחוזי הצלחה ללא מדידה; לא להציג חומרי טיוטה כחומר סופי.

## איך לעבוד בשיחה הבאה
1. פתחו את `course-workspace/COURSE_INDEX.md` כדי לבחור שיעור.
2. עיינו ב-`DECISIONS.md` ובהקשר הרלוונטי לשיעור.
3. משכתבו שיעור בקובץ נפרד תחת `lessons/` לאחר חילוץ ובדיקת הגרסה המקורית.
4. עדכנו סטטוס ומקורות. **אל תסמנו שיעור Approved בלי אישור בעל הקורס.**

## שמירת המקור
המסמך `Candlesticks_Course_Assembly_Working_v03.pdf` מ-13.10.2026 מכיל 163 עמודים ומוגדר כגרסת עבודה לביקורת. הוא טרם הועלה לתיקייה זו. אין לשחזר ממנו תוכן מהזיכרון בלבד; יש להשתמש במסמך המקורי כאשר מבצעים חילוץ לשיעורים.

## הפרדה מהאתר
זוהי תיקיית תיעוד ושיתוף פעולה בלבד, מחוץ לתיקיית `site/` ומחוץ ליישומי `apps/`. אין לייבא אותה לבאנדל, לקשר אותה לדפים, או להוסיף אותה לתהליך הפריסה.
