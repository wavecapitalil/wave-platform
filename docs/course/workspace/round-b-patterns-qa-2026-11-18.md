# Wave Capital — סבב ב׳: הרחבת תרגול תבניות והמחשות
תאריך: 2026-11-18
סטטוס: עדכון GitHub בוצע; בקרת דפדפן ומקור הנתונים החי טרם הושלמו.

## היקף
- יחידה 4: 12 שיעורים (4.1–4.12).
- נוספו 24 שאלות אינטראקטיביות, שתי שאלות לכל שיעור, עם תשובה נכונה, נימוק ודוגמה נגדית.
- נשמרו 18 כרטיסיות הזיהוי המקוריות בשיעור 4.5 ללא שינוי.
- רכיב גרפים היסטוריים לפי דרישה: BTC-USD יומי, 2024-03-01 עד 2024-03-28 UTC, מקור Coinbase Exchange API.
- הרכיב מציג נתוני OHLCV רק אם הם התקבלו מה־API ועברו בדיקות תקינות: תאריכים בטווח, ערכים סופיים, low ≤ open/close ≤ high, נפח לא שלילי, הסרת כפילויות ומינימום 12 נרות.
- בחוסר קישוריות, כשל CORS, API או נתונים בלתי תקינים — מוצגת הודעה ואין שימוש בנתוני דמה.
- הקורס שומר 9 יחידות / 56 שיעורים, מזהים קיימים ונתוני השלמה קיימים.

## בדיקות שבוצעו
- JSON מפוענח: 12 שיעורים / 24 שאלות.
- כל מזהי השאלות ייחודיים.
- לכל שאלה מספר אפשרויות תקין, אינדקס תשובה בטווח, הסבר ודוגמה נגדית.
- בדיקת תחביר JavaScript עברה.
- בדיקת קישורי הנכסים ב־HTML ובדף תוכן הקורס עברה בבדיקת טקסט.
- CSS חדש כולל התאמה לנייד ולמקלדת.

## חסמים לאימות סופי
- לא בוצעה בדיקת רינדור חיה בדפדפן או בדיקת רספונסיביות עם צילום מסך.
- מקור Coinbase לא היה נגיש מסביבת הכלים בזמן העריכה; טעינת נתונים אמיתיים באתר תלויה בנגישות API וב־CORS אצל המשתמש. לפיכך **אין לטעון שנתוני השוק עצמם אומתו בטעינה חיה**.
- גרפי Coinbase הם כלי אימון לקריאת OHLC, ולא נטען שנבחרו בהם דוגמאות מדויקות לכל אחת מתבניות יחידה 4.
- שימור מערך האיורים המקורי אינו מהווה אימות מול כל דפי המקור ההיסטוריים.
