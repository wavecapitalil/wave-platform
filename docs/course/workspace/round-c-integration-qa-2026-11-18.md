# WAVE CAPITAL — סבב ג׳: אינטגרציה ובדיקת שליטה
תאריך: 2026-11-18
סטטוס: קוד, תוכן והטמעה במסלול הלימוד ב־GitHub בוצעו. **בדיקת דפדפן חיה טרם בוצעה**.

## תכולת ההטמעה
- יחידה 9, חמישה שיעורים קיימים בלבד (9.1–9.5). אין שינוי במספר 56 השיעורים או במזהי ההתקדמות.
- מעבדת שלושה תרחישים סינתטיים: נסיגה במגמה עולה; פריצה שנכשלת; דשדוש ואי־פעולה.
- מוצגים תשעה נרות תחילה. נדרשת נעילת שבע תשובות לפני חשיפת הנר העשירי: תיאור מצב, ראיה תומכת, ראיה סותרת, תנאי אישור, תנאי ביטול, תוכנית סיכון/אי־פעולה והחלטה.
- חשיפה מדורגת של נר אחד בכל פעם; הרשומה המקורית אינה ניתנת לעריכה בדף אחרי הנעילה.
- רפלקציה נפרדת עם התייחסות למה שהתרחש בהמשך.
- יומן החלטות ב־localStorage וייצוא JSON. אין שמירה בענן/שרת, אין מסחר אמיתי או נתוני שוק מאומתים.
- גרפים בסגנון נרות יפניים על רקע נייבי וציר מחיר מימין.
- התאמה קיימת: 9.1–9.2 ו־9.5 מעבדה; 9.3–9.5 יומן.
- חמש הרחבות טקסט בתוך יחידה 9 להסברת התהליך.

## בקרות שבוצעו
1. JSON של יחידה 9 מפוענח ומכיל חמישה שיעורים.
2. שתי יחידות JavaScript עוברות בדיקת תחביר.
3. דף יחידה 9 מפנה לגרסאות הנכונות של קובצי JS ו־CSS.
4. המסלול הראשי מפנה לחמשת שיעורי יחידה 9.
5. הלוגיקה מונעת חשיפה דרך בקרת UI לפני שנשמרת רשומה נעולה.
6. הישגים מדווחים כשלמות התיעוד בלבד, לא כמדידת יכולת חיזוי/רווחיות.

## מגבלות ואתגרים ידועים
- נתוני הגרפים **סינתטיים**; אין הצגת תשואה אמיתית או בדיקה סטטיסטית של אסטרטגיה.
- נעילה היא ברמת ממשק ו־localStorage; תלמיד מתקדם יכול לשנות אחסון מקומי. לכן זו הגנה פדגוגית מפני Lookahead Bias, לא מערכת בחינה מאובטחת או הרשאה בשרת.
- טרם בוצעו בדיקת רינדור, ניווט מקלדת מלא, בדיקת מובייל עם דפדפן חי או בדיקת URL ציבורי לאחר GitHub Pages deploy.
- המנוע המקורי של סימון השלמת שיעור נשמר ללא שינוי; אין הסמכה אוטומטית בתום תרגיל.
