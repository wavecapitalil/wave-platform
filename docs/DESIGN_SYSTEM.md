# WAVE Shared Visual Language

The Terminal should visually belong to the same product family as WAVE University.

## Source of truth

The first token pass is intentionally based on the current University design language:

- background: #050c15
- panel: #091827
- secondary panel: #0c2035
- border: #173752
- strong border: #244e73
- text: #edf6ff
- muted: #90a8c2
- primary blue: #55aaff
- light blue: #9bd1ff
- green: #48d18a
- amber: #ffc857
- red: #ff6f82
- purple: #b99cff
- cyan: #58d7e8

## Shared style principles

- dark navy rather than near-black;
- subtle radial background light;
- rounded 14–24px surfaces;
- restrained blue borders rather than bright outlines;
- sticky glass navigation;
- high information density without looking cramped;
- blue/cyan accents for navigation and structure;
- green/amber/red reserved for state and meaning;
- consistent rounded inputs, pills and buttons;
- responsive behavior on iPad/mobile.

## Migration strategy

The current Terminal remains functional while a CSS compatibility layer brings its legacy components into the University visual language.

Later, as the Terminal moves to component architecture, these tokens should become the shared package used by:
- Main WAVE site
- Terminal
- University
- Products
- Research
