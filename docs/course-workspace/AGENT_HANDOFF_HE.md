# הוראה לסוכן ההטמעה

הטמע את הנכסים המצורפים באתר הקורס בהתאם ל־`manifest.json`. השתמש ב־`lesson_id` כדי לשייך לשיעור. אל תטען את כל האיורים בעמוד אחד באתר הייצור. בנה רכיבי React/Vue/HTML בהתאם לסטאק הקיים.

**הדגמות אינטראקטיביות עובדות:** `interactive/reveal.html`, `interactive/chart-lab.html`, `interactive/image-zoom.html`. הן מבוססות על נתונים סינתטיים עצמאיים ולא הופכות את תמונת המקור לנתוני נרות חיים. השתמש בהן כדפוסי UI ותרגם לנתוני OHLC מפורשים כשזמינים.

**הנחיות UX:** בחשיפה הדרגתית אותם נרות נשארים זהים, אותו טווח ואותו סולם. כל אירוע מוסיף שכבת הסבר או המשך מימין; לעולם לא מחליף את הגרף בגרף אחר. גרפים הקשריים בסגנון פרימיום נקי עם ציר מחיר מימין; איורים אנטומיים פשוטים. צבעים במשורה, תמיד עם תוויות.

**גבולות התוכן:** נרות בודדים וזוגות בלבד כתבניות שמיות; אין להטמיע צורות של 3+ נרות ממדריך המקור. אין להציג צילום הדמיה כאותנטי או להשתמש בלוגו של TradingView כשותף מסחרי.

**לבדיקה לפני Merge:** מיפוי מדויק לפסקה בשיעור, תיאום הגדרות OHLC, בדיקת מקלדת ו־ARIA, ביצועים בנייד, Lazy Load, טעינת תמונות WebP בעת הצורך, ושמירת נכסי מקור לשחזור.
